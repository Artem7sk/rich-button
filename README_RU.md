# PaidFlow 0.4.0 — тестовая Android-версия

Приложение для ведения клиентов и простых коммерческих счетов на Android 8.0+. Все данные остаются в приложении на телефоне; распознавание изображений выполняется локально и не требует интернет-соединения.

## Изменения 0.4.0

- Исправлено чтение фотографии после камеры. Статус распознавания и ошибки остаются в форме; черновик восстанавливается при пересоздании экрана во время съёмки.
- При неизвестном покупателе предлагается создать клиента прямо в счёте; найденные реквизиты покупателя переносятся отдельно от реквизитов поставщика.
- Исправлен разбор строки «Итого», которая могла ошибочно добавляться как товар.
- Поиск клиентов по имени, БИН/ИИН, телефону и email; остаток задолженности в карточке клиента.
- Создание похожего счёта с новым номером и сроком без переноса старых оплат.
- Отчёт по задолженности: в срок, просрочка 1–30 / 31–60 / более 60 дней, отдельно по каждой валюте.
- Экспорт всех счетов в CSV через системное окно сохранения Android.
- Полные реквизиты своей организации и клиента в PDF; старые счета сохраняют прежние реквизиты.

Это сборка для проверки функций перед коммерческим выпуском. Платные подписки, облачная синхронизация и публикация в Google Play в неё не включены.

## Основные возможности

- Создание клиента прямо из формы нового счёта; клиент сразу выбирается в счёте.
- Редактирование неоплаченного или частично оплаченного счёта из его карточки. Номер, дата создания, реквизиты отправителя и журнал оплат сохраняются. Нельзя уменьшить сумму ниже уже учтённых оплат; после оплаты нельзя менять клиента и валюту.
- Создание счетов с несколькими позициями, поиск, фильтры, статусы просрочки и история оплат.
- Фото счёта камерой, выбор изображения из файлов/галереи или отправка изображения в PaidFlow из другого приложения через «Поделиться».
- Встроенный OCR на русском и английском. Фото счёта заполняет найденные позиции, количество, цены, итоговую сумму, клиента, срок оплаты и валюту; если строка таблицы не распознана, но найден итог, он добавляется одной проверяемой позицией.
- Фото реквизитов клиента заполняет название/имя, БИН/ИИН или ИНН, адрес, расчётный счёт/ИИК/IBAN, БИК/SWIFT, КБе, банк, телефон и email. Распознанный текст остаётся на экране для проверки.
- OCR запускается локально. Изображение и распознанный текст не отправляются на сервер. Перед сохранением проверь распознанные данные: качество фотографии и формат документов 1С и других программ влияют на точность.
- Сохранение счёта в PDF через Android, подготовка напоминания, резервное копирование и восстановление JSON.
- Русский и английский интерфейс; USD, EUR, GBP, KZT и RUB без конвертации валют.

## Установка и первый запуск

1. Установите тестовый APK. Android может попросить разрешить установку из выбранного браузера или файлового менеджера.
2. В разделе «Ещё» сохраните имя бизнеса и реквизиты.
3. Создайте счёт. Добавьте клиента вручную или нажмите «Распознать счёт по фото»; проверьте распознанные поля до сохранения.
4. Проверьте заполненные распознаванием поля, затем сохраните.
5. Для PDF откройте счёт, нажмите «Сохранить счёт в PDF» и выберите «Сохранить как PDF» в окне печати.

Чтобы передать изображение из другого Android-приложения, используйте его команду «Поделиться» и выберите PaidFlow. Если приложение отправляет PDF вместо изображения, сохраните страницу счёта как изображение/снимок экрана и выберите его в PaidFlow.

## Проверки и ограничения

- APK с тестовой подписью предназначен для установки и проверки, он не является релизом Google Play. Обновление опубликованной версии будет выполняться через Google Play; в приложении отключена установка APK из сторонних источников.
- OCR использует Tesseract4Android и закреплённые английскую и русскую модели. Список лицензий и источников указан в [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md).
- Данные счета и клиентов хранятся локально, облачной синхронизации и подключения к банку нет. Экспортированный JSON не зашифрован и содержит личные данные клиентов. Удаление приложения удаляет базу; заранее сохраните резервную копию.
- Оплаты отмечаются вручную. Приложение не проверяет банковские операции и не отправляет напоминания самостоятельно.
- PDF — обычный коммерческий счёт без отдельного расчёта налогов; он не является фискальным чеком или заменой бухгалтерии.
- До 100 позиций в счёте; количество целое от 1 до 100000; до 10000 клиентов и счетов; размер резервной копии — до 10 МиБ.
- Для публикации в Google Play потребуются защищённая подпись приложения, страница приложения, политика конфиденциальности и прохождение проверок Play. Тестовый ключ из репозитория нельзя использовать для публикации.

## Сборка и тесты

Нужны JDK 17, Android SDK Platform 36 / Build Tools 36.0.0, Gradle 8.13, `bash`, `curl`, `git` и доступ к Google Maven/JitPack для загрузки библиотек. Новые приложения Google Play с 31 августа 2026 года должны целиться в Android 16 (API 36). При сборке Gradle автоматически скачивает OCR-модели из зафиксированного коммита официального `tessdata_fast` и проверяет их Git-хеши.

```sh
node --test tests/core.test.cjs
npm install --no-save playwright@1.51.1
npx playwright install chromium
node tests/scan-ui.cjs
node tests/ui.cjs
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. CI подписывает тестовый APK автоматически созданным debug-ключом runner. После новой сборки Android может потребовать удалить предыдущую тестовую версию перед установкой. Для обновлений опубликованной версии применяется отдельный ключ подписи Google Play.

GitHub Actions выполняет те же проверки и публикует APK как артефакт `PaidFlow-test-APK`. Для сборки в Actions запустите workflow **PaidFlow Android** вручную или отправьте изменения в `main`, `master` или `paidflow`.

Для подписанного Play App Bundle есть отдельный workflow **PaidFlow Play bundle**. Перед запуском добавьте в GitHub Actions Secrets `PAIDFLOW_UPLOAD_KEYSTORE_BASE64`, `PAIDFLOW_UPLOAD_STORE_PASSWORD`, `PAIDFLOW_UPLOAD_KEY_ALIAS` и `PAIDFLOW_UPLOAD_KEY_PASSWORD`; путь к keystore workflow создаёт во временной папке runner. Workflow только собирает AAB и отдаёт его артефактом — публикацию и заполнение Play Console выполняет владелец приложения. Не отправляйте ключ в репозиторий или чат.
